## ⚠️ 重要：データおよび分析内容について（必ずお読みください）

* **非公式・ポートフォリオプロジェクト (Unofficial / Portfolio Project)**:
  本プロジェクトは、株式会社紀伊國屋書店およびその関連会社・海外法人が公開している実際の内部データを使用したものではなく、個人がデータ分析・SQLスキルを実証するために構築した**独自の分析用シミュレーションプロジェクト**です。

* **実在企業の内部データは一切使用していません**:
  本プロジェクトで使用する売上、顧客、注文、商品、購買履歴、RFM等のデータは、**紀伊國屋書店の実際の売上データ、顧客データ、購買履歴、社内データ、機密情報等ではありません。**

* **疑似データ（Simulated / Dummy Data）について**:
  本プロジェクトで使用するデータは、**紀伊國屋書店の公開情報、公開されている商品・サービスの構成、一般的な書店・EC市場におけるデータ構造やビジネスモデルを参考に、分析・SQL実装のためにゼロから設計・生成した完全な疑似データ（ダミーデータ）**です。

* **公開情報と分析用疑似データは明確に区別しています**:
  公開情報は、実際の事業構造や商品カテゴリー等を想定する際の**参考情報**としてのみ使用しています。
  その公開情報から実際の売上金額、顧客数、購買頻度、RFMスコア等を推定・再現したものではありません。
  本プロジェクト内の数値は、**分析手法を実装するために独自に生成したシミュレーション値**です。

* **分析結果について**:
  本プロジェクトから得られる売上、成長率、顧客セグメント、商品トレンド等の分析結果は、実際の紀伊國屋書店の事業実績や顧客行動を示すものではありません。
  あくまで、**架空のデータセットに対してSQLによる分析を行った場合の技術実証例**として扱ってください。

## 📌 プロジェクト概要

本プロジェクトでは、紀伊國屋書店のような**国内外で書籍・漫画・雑誌・関連商品等を取り扱うグローバルな書店・ECビジネス**を分析対象として想定し、日本市場と米国市場を比較するSQL分析環境を構築します。

紀伊國屋書店は日本国内だけでなく海外にも事業を展開しており、米国では日本語・英語の書籍、漫画、アート・デザイン関連書籍、文具・ギフト等を取り扱っています。

これらの**公開されている事業・商品構成を分析テーマの参考情報として使用し、実際の社内データではなく、一般的な書店・EC市場のデータ構造を参考にした疑似データを独自に設計**します。

その疑似データを用いて、以下の3つの観点からSQLによるデータ分析を行います。

---

## 🎯 分析テーマ

### ① Cross-border Sales Analysis

日本市場と米国市場を比較し、

- 売上高
- 購入者数
- 購入回数
- 1人あたり購入金額
- 商品カテゴリー別売上

などのKPIを分析します。

**目的：**
グローバルに展開する書店・ECビジネスにおいて、市場ごとの売上構造を比較する。

---

### ② Anime / Manga Growth Trend Analysis

漫画・アニメ関連商品の売上推移を分析し、

- 年次売上
- 市場別売上
- 商品カテゴリー別売上
- 前年比（YoY）
- 成長率

などを算出します。

**目的：**
日本市場と米国市場における、漫画・アニメ関連商品の成長トレンドを比較する。

---

### ③ Localized Customer RFM Analysis

顧客の購買履歴から、

- Recency（最終購入からの経過日数）
- Frequency（購入頻度）
- Monetary（購入金額）

を算出し、顧客をRFMによってセグメント化します。

さらに日本・米国などの市場別に顧客構成を比較します。

**目的：**
市場ごとの顧客購買行動の違いを分析し、ローカライズされたマーケティング施策を検討する。

---
